Agent Under Watch

Your agents have tools. Your SOC should have questions. Correlate agent lifecycle, identities and endpoint activity. Investigate evidence—not just usage.

Offline release preview — no tenant connection and no live metrics. This page describes the packaged workbook and rules. It is not a simulation of real findings. All analytics deploy disabled; optional agent events require a separately configured producer.

Packaged analytics

NATIVE

Agent rapidly created and published by an unapproved maker

Successful creation followed within 30 minutes by publication of the same observed BotId by the same UPN in the same environment, without an enabled matching maker approval. Includes unregistered agents; inventory enriches registration status only.

Medium · exact · disabled by default
NATIVE

Registered agent authentication configuration changed

Successful Copilot Studio BotAuthUpdate on a known enabled agent; reports configuration change without asserting weakened authentication.

Low · configuration · disabled by default
NATIVE

Permission assignment audit targets a registered agent identity

Successful Entra app-role assignment or delegated permission grant audit whose ServicePrincipal target ID matches an enabled agent inventory identity; a configuration review signal, not an escalation claim.

Medium · configuration · disabled by default
NATIVE

Registered agent identity signs in after a permission audit

Permission audit targeting a known agent service principal followed within 30 minutes by a successful service-principal sign-in with the same object ID.

Medium · heuristic · disabled by default
NATIVE

Registered agent runtime spawns a shell with network activity

A registered endpoint runtime directly creates a selected shell or script host, followed within 10 minutes by a successful connection from that exact child process instance.

Medium · heuristic · disabled by default
NATIVE

Registered agent runtime contacts a new non-allowlisted destination

Successful runtime connection to a hostname absent from both the enabled per-agent allowlist and the preceding observable portion of a 14-day baseline; requires at least three observed baseline days.

Low · heuristic · disabled by default
OPTIONAL

Optional: injection signal followed by a successful agent action

Normalized custom injection signal followed strictly later within 10 minutes by a successful tool invocation or external submission in the same registered agent session.

Medium · heuristic · disabled by default
OPTIONAL

Optional: sensitive-data access followed by a non-allowlisted tool submission

Successful normalized Confidential or HighlyConfidential data access followed strictly later within 10 minutes by successful external tool submission in the same agent, session and nonempty correlation context.

High · heuristic · disabled by default
